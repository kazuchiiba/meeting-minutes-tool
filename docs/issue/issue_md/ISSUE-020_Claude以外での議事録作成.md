## 何が起きているか・何が分からないか

議事録作成（④）は Claude が行っている。Aさんから、今後 Claude 以外で代替できないかも試したいという要望があった。

## 根拠

- 2026/11/23 Aさん（ISSUE-017 の回答）
- 作成ルールはスキルの `references/writing-rules.md` と `format-spec.md` にファイルとしてまとめてあるので、他のモデルにも同じルールを渡せる。
- 自己点検（⑤）はスクリプトなので、どのモデルの出力にも同じ基準で使える。

## 選択肢

| 案 | 内容 | 良い点 | 懸念 |
|---|---|---|---|
| A | ローカルで動く LLM（オープンモデル）で④を行う | 文字起こしのテキストも社外に出ない | CPU のみでは非常に遅い。日本語の長文の質が不明 |
| B | 他社のクラウド LLM で④を行う | 比較ができる | テキストを社外に送る点は Claude と同じ。社内ルールの確認が必要 |
| C | 比較の方法を先に決める：同じ文字起こし・同じ作成ルールで作り、⑤の自己点検と人手版との比較で評価する | 公平に比べられる | 評価の手間 |

推奨：C の評価方法を決めてから、A・B を試す。

## ソフトへの影響

④を差し替えられるよう、作成ルール・入力・出力（md の書式）をモデルに依存しない形で保つ。
