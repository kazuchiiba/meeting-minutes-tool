## 何が起きているか・何が分からないか

R にあって C にない項目が8件あった。ISSUE-004 の決定（AI は拾えるものをすべて拾う）に反している。ヒアリングでは R がほぼ全発言を拾っているので、抜けがそのまま差になる。

## 根拠

| R の項目 | 抜けた理由（推定） |
|---|---|
| 取引先S の特値はあるか → 基本ない（I・B） | 文字起こしが崩れていて Claude が飛ばした |
| 受発注システム が価格改定のタイミングでバッチを回して通知すればよい（F） | 「手事故が…バッチリと」と崩れていた |
| Oさんに、今後もやった方がよいと言われた（B） | 人名が「Oさん」と崩れていた |
| これは営業企画Gの仕事だと思う（H） | 「国民って企画」と崩れていた |
| Mさん等から採用購買の話が来る（B） | 「Mさんとか採用勾配で」と崩れていた |
| 納品日基準で価格が変わる商品があると困る（F） | 文字起こしは読める状態。Claude が要約で落とした |
| PHP の時の強制検収の影響か（A） | 文字起こしは読める状態。Claude が要約で落とした |
| 違算処理の時は別途帳票を作るのか（A） | 文字起こしは読める状態。Claude が要約で落とした |

## 選択肢

| 案 | 内容 | 良い点 | 懸念 |
|---|---|---|---|
| A | 崩れた箇所も飛ばさず【聞き取り不明】として残す（ルールの明確化） | 抜けが見える。人が音声で確認できる | 印が増える（ISSUE-007） |
