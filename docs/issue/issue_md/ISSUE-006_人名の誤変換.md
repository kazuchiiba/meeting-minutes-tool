# ISSUE-006 人名の誤変換

## 何が起きているか・何が分からないか

参加者以外の人名（会話に出てくる関係者）が誤変換され、Claude は気づけなかった。人名は誤っていても文として自然なので、【推定】も付かない。

## 根拠

| 文字起こし | 正しい名前（R） | C の扱い |
|---|---|---|
| Lさん | Lさん | Lさん（無断の誤り） |
| 二等差（のツール） | Gさん（のツール） | 【聞き取り不明】 |
| Aさん | Aさん（参加者） | 参加者名簿から補正できた |
| Sチームリーダー | R は「オーダーみらいで」 | どちらが正しいか未確定（ISSUE-010） |

参加者の名前は名簿を渡していたので補正できた。参加者以外の関係者（Lさん、Kさん、Nさん、Qさんなど）は名簿がない。

## 選択肢

| 案 | 内容 | 良い点 | 懸念 |
|---|---|---|---|
| A | 関係者名簿（部署内・よく出る人）を用語集と一緒に渡す | 誤変換を直せる | 名簿の管理が必要。個人情報の扱いに注意 |
| B | 人名らしき語をすべて【要確認】として一覧に出す | 名簿がなくても人が確認しやすい | 確認の手間が残る |
| C | A＋B（名簿にない人名だけ一覧に出す） | 確認対象を絞れる | — |

推奨：C。

## ソフトへの影響

- 用語集（ISSUE-005）に人名の欄を設ける。
- 議事録の末尾か別ファイルに「確認が必要な人名・用語」の一覧を出す。

## 決定内容

2026/11/23 Aさん：案 C。名簿を確認し、分からなければマーキングして、人が最後に修正する。
- 対応：作成ルール12として `.claude/skills/minutes/references/writing-rules.md` に追加。会話に出る人名は用語集の「人名」シート（名簿）で確認し、名簿にない・表記が確かでない人名は `氏名【要確認：人名】` として残す。⑦で【推定】【聞き取り不明】の人名は用語集の候補にも上がる。
