## 分かったこと

1. **話者分離ありの方が、発言の抜けが少ない。** 話者分離ありでは、pyannote の発話区間で抜けを補完できた。話者分離なしでは、Silero VAD で区切り直しても次の発言が文字起こしに残らなかった。
   - 1:18〜1:56 取引先Pと kintone を共有する話
   - 10:23〜11:53 マスター更新候補ツールの説明（住設機器はすぐ作れる、ガス機器は形が決まっていない）
   - 12:11〜13:25 起案アプリとの関係、14:26 「役割が全然違う」、15:13 起案アプリの明細の表の説明
   - 17:17〜17:33 カットオーバーの質問と「12月末からテストで運用」
   - 18:07 「アプリの説明は別でする」、29:43 閉会と、その後の予定の連絡
   - 話者分離なし版の最初の議事録には、これらの一部が書かれていた。最初の補完版の文字起こしにはあったが、作り直した版で消えていた。レビューで「付け足し」と指摘されて削除したが、実際には話されていた内容だった。**区切って再実行した補完で、発言が消えている可能性が高い**（ISSUE-026 に追記が必要）。
2. **発言者は、話者分離ありの方がずっと多く付けられる。ただし記号どおりではない。** 6つの記号のうち、人とほぼ1対1に対応したのは SPEAKER_05（H）と SPEAKER_02（C）だけ。SPEAKER_04 にはD・I・司会が混ざり、1つの記号の中でも途中で人が変わる箇所があった。Fさんの発言は判別できなかった。対応付けは Claude の推定なので、ほとんどが【推定】になる。
3. **処理時間は、話者分離ありが約1.5時間長い。** CPU で②が約46分、③が約54分かかった。話者分離なしでも、補完のやり直しを含めると約60分かかっている。
4. **レビュー Agent は、どちらでも書き手の見落としを見つけた。** 話者分離なしでは主に付け足し・確度の格上げ、話者分離ありでは主に発言者の振り分けと印のない言い換えだった。
