## 4. 一次所見（CI のみ）

**内容の拾い漏れ**：R に書かれた議題11件は、すべて C にも含まれていた。

**C が R に届かない点**：
1. 書式（見出しの切り方、発言者を末尾に書く、敬称略、一人称）が違う。→ 書式の指定で解決できる見込み。
2. 取捨選択をしていない。R は業務論点に絞って約2,000字、C は全部書いて約5,500字。→ 何を省くかの基準が必要。
3. 社内用語と人名の誤変換を直せない。不確かな箇所に印を付けても、正しい語には届かない。→ 用語集・人名簿が必要。
4. 日時・場所・所属が音声に入っていない。→ 予定表など別の情報源が必要。

**C の方が良かった可能性がある点**：決定事項・宿題の整理、R の誤記（「E」）や解釈の揺れがないこと。ただし解釈の揺れは、正解データを作るまで確定しない。
