## 5. 一次所見（Bさんヒアリング）

1. **話者の対応付けが崩れた**：司会が順番に指名する CI と違い、ヒアリングでは名前で呼ばれる場面が少ない。1か所の呼びかけの聞き違い（F→F）で13発言の話者を誤った。ヒアリングでは対応付けを AI に任せられない。
2. **文字起こしの品質が低い**：Bさんの早口の説明、社内用語・取引先名の多さで、CI より誤変換が多い。聞き取りにくい箇所を C が飛ばし、R にある項目が抜けた。
3. **印なしの誤った言い換えが3件あった**：C のルール違反（言っていないことを書かない）。用語を知らないまま、もっともらしい一般語に置き換えた。
4. **書式**：ヒアリングは「取引先/区分：内容」の見出しと画像の差し込み枠があり、CI と書式が違う。
5. **良かった点**：R の主要な話題（業務負荷、取引の仕組み、価格提示の流れ、部署4との役割分担、リベート、違算・入金連絡、1円の端数差、在庫提案、取引先R、取引先Q）はすべて C にもあった。
