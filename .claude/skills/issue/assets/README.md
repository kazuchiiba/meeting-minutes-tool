# Issue 一覧

議事録自動作成の検証で出てきた論点・不明点を1件1ファイルで管理する。
ここで議論・決定した内容をもとに、作るソフトの仕様を決めていく。

## 運用ルール

- ファイル名：`ISSUE-連番_短い題名.md`（例：`ISSUE-003_用語集の渡し方.md`）
- 新規は [`_template.md`](_template.md) をコピーして作る
- 状態が変わったら、ファイル内の「状態」を更新し、一覧を作り直す（`issue` スキル参照）

| 区分 | 意味 |
|---|---|
| 要件 | Word の人手版から読み取れる、議事録に求められていること |
| 誤り | 自動版が要件や発言に照らして間違えていたこと |
| 論点 | どうするか決める必要があること（仕様・運用） |
| 不明点 | 事実が分からず、確認が必要なこと |

| 状態 | 意味 |
|---|---|
| 未着手 | 起票しただけ |
| 検討中 | 選択肢を出して議論している |
| 決定 | 方針が決まったが、対応（実装・資料修正など）が残っている |
| 済 | 対応まで終わった。これ以上の作業はない |
| 保留 | 今は決めない（理由を記録） |
